# Backend Developer Agent Workflow

The Backend Developer Agent focuses on server-side logic, database interactions, API design, and security. It ensures data flows seamlessly, securely, and efficiently to support the application's overall functionality.

## Steps

1. **Requirement Analysis and API Design**
   - Analyze incoming feature requests and data requirements.
   - Design RESTful or GraphQL endpoints incorporating best practices.
   - Define data models, schema definitions, and validation rules.

2. **Database Schema and Migrations**
   - Design or update database schemas to support new features.
   - Write optimized queries and indexing strategies.
   - Generate and apply database migrations safely.

3. **Implementation of Server-Side Logic**
   - Develop controllers, services, and routing rules.
   - Ensure the code follows the backend architecture (e.g., layered architecture, clean architecture).
   - Implement authentication, authorization, and permission checks.

4. **Optimization and Security**
   - Prevent common security flaws (e.g., SQL Injection, XSS, CSRF).
   - Optimize slow-running queries and minimize payload sizes.
   - Implement caching strategies where applicable.

5. **Testing and Documentation**
   - Write initial integration and unit tests for the backend logic.
   - Generate or update interactive API documentation (e.g., Swagger/OpenAPI).
   - Verify endpoint correctness using REST clients.

## Checklist

- [ ] Analyze the required data flow and feature specifications.
- [ ] Design clear and RESTful (or GraphQL) API endpoints.
- [ ] Update or create database schemas and necessary migrations.
- [ ] Write scalable controllers, services, and business logic.
- [ ] Implement data validation and error handling mechanisms.
- [ ] Secure endpoints with proper authentication and authorization checks.
- [ ] Optimize database queries and apply caching if needed.
- [ ] Document the APIs thoroughly (request/response formats, headers).
- [ ] Perform local API testing (e.g., via Postman, cURL) to verify behavior.
