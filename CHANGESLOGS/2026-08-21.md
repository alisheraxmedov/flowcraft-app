# 2026-08-21

## Architecture
- Converted the repo from a Flutter package (`lib/` + `example/`) into a
  standalone Flutter app living at the repo root — no more package-shaped
  scaffolding, `example/` merged into `android/`, `ios/`, `linux/`, `macos/`,
  `windows/`, `web/`.
- Reorganized `lib/` and `test/` into MVVM layers: `models/`, `viewmodels/`,
  `views/` (+ `views/widgets/`), `services/`, `core/` (canvas, domain,
  rendering, interactions, serialization, utils).
- Adopted Riverpod for state management — `ThemeViewModel` and `McpViewModel`
  as `Notifier`s, `SketchController` exposed via a DI-only `Provider` (kept as
  a plain `ChangeNotifier` internally; Riverpod 3 has no public
  `ChangeNotifierProvider`).

## New Features
- Centralized "Kinetic Blueprint" design-token theme system
  (`lib/core/theme/`: colors, typography, spacing, radius) applied across the
  entire app chrome, theme-aware via `Theme.of(context).colorScheme` so the
  dark/light toggle actually changes the UI.
- Rebuilt the top bar as a real `AppBar` with `actions`, a floating tool rail,
  a new **Properties panel** (edit position/size/stroke/fill of the selected
  element, JSON edit dialog), and a restyled MCP/system status card.
- App startup **splash screen** — animated glowing logo, waits on real MCP
  control-server startup (with a timeout fallback so a slow/failed server
  never traps the user), then hands off to the whiteboard.

## Bug Fixes
- Dark/light theme toggle previously did nothing visible — chrome widgets
  read hardcoded colors instead of the live theme; now theme-aware throughout.
- Properties panel dimension edits (X/Y/W/H) silently bypassed undo history —
  now wrapped in a drag session like every other resize.
- Diamond and triangle tool icons were swapped; eraser used an unrelated
  "cleaning" icon and its tool could get scrolled out of reach on short
  windows — icons fixed (`material_symbols_icons` for a real eraser glyph),
  tool rail now defaults to a single column and only wraps to two when the
  window is too short to fit one.
- Splash screen text rendered with a stray underline (no `Material` ancestor
  behind the `Text` widgets) — fixed.

## Code Quality
- Deleted a dead, never-instantiated toolbar widget (`SketchToolbar`).
- Split the 999-line `SketchToolbarRich` god-file into single-responsibility
  files under `lib/views/widgets/toolbar/`.
- Deduplicated hit-test, rotation, and arrow-head math that was copy-pasted
  across every shape type.
