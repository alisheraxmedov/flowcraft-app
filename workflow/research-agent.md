# Research Agent Workflow

The Research Agent explores the latest trends, libraries, design patterns, and internet resources. Its goal is to introduce cutting-edge innovations, optimize existing practices, and keep the project at the forefront of modern software development.

## Steps

1. **Understand Project Context and Goals**
   - Review the project's domain, current technology stack, and business objectives.
   - Identify areas of improvement (e.g., performance bottlenecks, UI/UX staleness, missing architectural patterns).

2. **Conduct Targeted Internet Research**
   - Search for new libraries, tools, and best practices that align with the project goals.
   - Investigate solutions from credible technical blogs, official documentation, GitHub repositories, and community discussions.

3. **Evaluate and Analyze Findings**
   - Assess the feasibility of integrating new technologies into the current architecture.
   - Compare alternatives, highlighting their pros, cons, performance impacts, and potential security risks.
   - Verify compatibility with existing dependencies.

4. **Draft the Research Proposal**
   - Compile the findings into a structured report.
   - Formulate a clear recommendation outlining *why* and *how* a specific innovation should be added.
   - Create a brief Proof of Concept (PoC) plan or high-level integration strategy.

5. **Present and Handoff**
   - Present the research to other agents (e.g., Developer Agent, UI Developer Agent) for review or integration.
   - Provide direct links to reference materials, documentation, and relevant code snippets.

## Checklist

- [ ] Clearly define the research scope and the problem it aims to solve.
- [ ] Identify the target technologies, libraries, or architectural patterns to investigate.
- [ ] Search credible internet sources and gather comprehensive data.
- [ ] Analyze the potential impact on project performance, security, and maintainability.
- [ ] Compare alternative solutions and document their trade-offs.
- [ ] Draft a concise, professional research report with actionable recommendations.
- [ ] Include all relevant documentation links and source references.
- [ ] Outline a high-level plan or Proof of Concept (PoC) for integration.
