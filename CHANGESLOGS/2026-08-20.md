# 2026-08-20

## Whiteboard Refactor
- Repositioned flowcraft as a Miro / Excalidraw-style interactive whiteboard.
- Removed the legacy node/edge/engine pipeline (`lib/engine`, `lib/nodes`,
  `lib/edges`, `lib/handles`, `lib/interactions`, `lib/overlays`,
  `lib/controller`, `lib/theme`, `documentation/`, `workflow/`) in favour of a
  single clean `WhiteboardCanvas` host.

## New Features
- **Triangle tool** — sketchy triangles with optional centred inline text that
  follows the shape when it is resized.
- **Sticky notes** — native `SketchSticky` element in the brand colour, with
  auto-opened inline text editing on creation.
- **Shape resizing** — bottom-right resize handle for rectangle, ellipse,
  diamond, triangle, and sticky notes, with a minimum size and full undo/redo
  history support.
- **Vertical toolbar** — the rich toolbar now renders vertically on the left
  edge alongside the grid and theme toggles.

## Bug Fixes
- Inline text no longer overlaps existing text while editing — the element being
  edited is now omitted from the painter layer.
- Real-time drawing preview repaints correctly (revision counter fix).
- Ellipses render as smooth circles again instead of an octagon-like polygon.
- **Arrow heads** — now drawn as a solid, filled triangle that scales with the
  stroke width instead of two thin cut lines, making the pointer clearly visible.

## UX Improvements
- Grid toggle button to show/hide the background grid.
- Dark / light theme toggle wired into the example app as a stateful screen.
- Double-tap (400 ms) on text elements in select mode opens the inline editor.
