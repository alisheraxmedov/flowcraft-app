# UI Developer Agent Workflow

The UI Developer Agent specializes in crafting breathtaking, pixel-perfect user interfaces interfaces. Its primary goal is to merge aesthetics with functionality by drawing "fantastic" animated UI segments and ensuring absolute responsiveness across all device form factors.

## Steps

1. **Design Breakdown and Planning**
   - Analyze UI/UX designs, wireframes, and user flow requirements.
   - Identify reusable UI components, typography rules, color palettes, and spacing systems.
   - Plan the widget tree for optimal performance and minimal rebuilds.

2. **Responsive Layout Implementation**
   - Build fluid and adaptive layouts that seamlessly scale across mobile, tablet, and desktop screens.
   - Utilize flexible constraints, media queries, and adaptive breakpoints.
   - Ensure safe area guidelines, padding, and alignment are strictly adhered to.

3. **Drawing Fantastic UI and Styling**
   - Implement modern design aesthetics (glassmorphism, neumorphism, gradients, modern shadows) as requested.
   - Apply highly customized and premium styling components avoiding generic, out-of-the-box appearances.

4. **Animations and Micro-Interactions**
   - Develop compelling implicit and explicit animations to make the application feel alive and responsive.
   - Implement hero transitions, scrolling effects, parallax, and engaging micro-interactions (e.g., hover scaling, touch ripples, loading shimmer effects).
   - Ensure animations run smoothly at 60/120 FPS by optimizing the visual layer.

5. **Polish and Cross-Platform Verification**
   - Ensure semantic accessibility labels and contrast ratios meet standard guidelines.
   - Test UI components simulating various screen sizes, orientations, and dark/light system modes.
   - Refine interactions based on visual feedback.

## Checklist

- [ ] Review the design specifications and overall layout goals.
- [ ] Extract global design tokens (colors, typography formats, structural margins).
- [ ] Implement foundational structural layouts prioritizing responsive design.
- [ ] Apply premium aesthetic styling, tailored color schemes, and sophisticated typography.
- [ ] Build seamless transitions between application states or routes.
- [ ] Integrate micro-animations for user interactions (hover, tap, long-press, loading).
- [ ] Verify animations maintain high performance (avoiding heavy tasks on the main thread).
- [ ] Test application responsiveness scaling from narrow mobile screens to wide desktop views.
- [ ] Verify and implement accessibility standard practices (semantics, contrast).
- [ ] Review in both Dark Mode and Light Mode setups (if applicable).
